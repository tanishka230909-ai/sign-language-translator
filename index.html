05 / ABOUT THE PROJECT

AI with a purpose.
Learning through creation.

Sign Language Translator is a student-developed AI prototype created to explore how image classification can support accessible communication.

The project uses a trained gesture-recognition model to identify selected hand poses, display their predicted labels and provide optional speech output. It brings together AI concepts, web development and a real-world accessibility challenge.

01

AI & Image Classification

Learning from labelled training examples

02

Web Development

HTML, CSS and JavaScript

03

Accessibility

Exploring additional ways to communicate

ⓘ

Understanding the prototype

This educational prototype recognises only the gestures represented in its training data. It is not a complete sign language translator, may make incorrect predictions and should not replace communication with fluent signers or qualified interpreters.
